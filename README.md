# Slag Dump Resistivity Survey

**Live dashboard:** [paste link]

**Simulated data:** 222 readings at 38 ground stations along a ~67 m line, modeled on published slag dump resistivity research. This is not real field data.

**Question:** Where along the line is the ground unusually conductive, and how does resistivity change with depth?

**Tools:** Python, Plotly, Jupyter Notebook

**Findings:**
- Resistivity ranged from about 4.5 to 32 ohm-metres, consistent with slag or waste fill.
- Resistivity decreases with depth, a statistically confirmed trend.
- A few stretches are notably more or less conductive and are priority targets for follow-up sampling.

**Files:**
- `resistivity_survey_analysis.ipynb`: the full analysis
- `dashboard.html`: interactive dashboard
- `executive_summary.docx`: one-page summary
